Kurz gesagt

Dies ist eine Zusammenfassung, keine Rechtsberatung. Maßgeblich ist der Lizenztext weiter unten.

  • Nutzen Sie appship in privaten, kommerziellen und Closed-Source-Projekten, ohne Gebühr.
  • Ändern Sie es und geben Sie Ihre Version weiter, oder binden Sie es in Ihre eigenen Werkzeuge ein.
  • Behalten Sie den Copyright-Hinweis und den Lizenztext in jeder Kopie oder wesentlichen Teilkopie bei, die Sie weitergeben.
  • appship wird ohne Gewährleistung bereitgestellt. Mit --dry-run sehen Sie vorab, was es tun würde, bevor es in einen Store schreibt.
  • Der vollständige Quellcode liegt im npm-Paket appship-ai.

Software von Drittanbietern

appship bündelt fastlane nicht. Es führt die Version aus, die Sie selbst installieren. Die npm-Abhängigkeiten installiert npm; sie behalten ihre eigene Lizenz.

KomponenteLizenzVerwendung
fastlaneMITFührt alle Store-Aufrufe aus. Nicht gebündelt, Sie installieren es selbst.
commanderMITAuswertung von Kommandozeilenargumenten
@inquirer/promptsMITInteraktive Abfragen
picocolorsISCFarben im Terminal
yamlISCLesen und Schreiben von release.yml

Jedes Paket und jedes Paket, von dem es abhängt, enthält nach npm install seine eigene Lizenzdatei.

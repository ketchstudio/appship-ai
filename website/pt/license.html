Software de terceiros

O appship não inclui o fastlane. Ele executa a cópia que você mesmo instala. As dependências npm são instaladas pelo npm e mantêm a própria licença.

ComponenteLicençaUso
fastlaneMITExecuta todas as chamadas às lojas. Não é incluído, você mesmo o instala.
commanderMITLeitura de argumentos de linha de comando
@inquirer/promptsMITPerguntas interativas
picocolorsISCCores no terminal
yamlISCLeitura e escrita do release.yml

Cada pacote, e cada pacote de que ele depende, inclui o próprio arquivo de licença após o npm install.

ひとことで言うと

これは要約であり、法的助言ではありません。効力を持つのは下記のライセンス全文です。

  • 個人、商用、クローズドソースのプロジェクトで、無料で appship を使えます。
  • 改変して自分のバージョンを共有したり、自作ツールに組み込んだりできます。
  • 配布するすべてのコピーまたは相当部分に、著作権表示とライセンス文を含めてください。
  • appship は無保証です。ストアに書き込む前に --dry-run で動作を確認してください。
  • ソースコード全体は npm パッケージ appship-ai に含まれています。

サードパーティのソフトウェア

appship は fastlane を同梱しません。ご自身でインストールした fastlane を実行します。npm の依存パッケージは npm がインストールし、それぞれのライセンスに従います。

コンポーネントライセンス用途
fastlaneMITすべてのストア呼び出しを実行します。同梱はしないため、ご自身でインストールします。
commanderMITコマンドライン引数の解析
@inquirer/promptsMIT対話式のプロンプト
picocolorsISCターミナルの色付け
yamlISCrelease.yml の読み書き

各パッケージと、その依存パッケージには、npm install 後にそれぞれのライセンスファイルが含まれます。
